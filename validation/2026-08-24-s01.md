## 核心不变式

- 本章普通子 Fiber 的 `dispose()` resolve 前，已登记 disposer 成功执行，资源计数回到 0；这由账本证明，不只依据 Promise resolve。
- 调用根 Fiber 的清理入口会递归卸载子 Fiber；清理后重新挂载并卸载探针 Plugin 成功，证明当前基线的根 Context 按 restart 语义保持可用。
- effect/disposer 之外获取的 `leaky-connection` 不会因为子 Fiber 销毁而自动释放。
- 负例被探针捕获后由实验宿主兜底清理，不污染后续测试。
- 本地 Markdown 链接可解析，上游源码链接固定到完整 commit。
- 章节结构测试要求先介绍 Context、Plugin、Fiber、Effect、Disposer 五个基本概念，避免直接用术语驱动实验。
- GitHub Actions 使用最小 `contents: read` 权限，第三方 action 固定到已核验且使用 Node 24 runtime 的稳定 release commit，并覆盖 Node `22.19.0` / `24`。
