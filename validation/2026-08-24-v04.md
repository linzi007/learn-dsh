# v0.4 验证：Persistence → Jobs → Compaction

## 范围

- S08：真实 JSONL persistence 的跨 Context 恢复、torn tail 修复与 committed corruption 拒绝。
- S09：真实 `LocalJobRegistry` 的增量读取、等待、取消、owner 隔离与 Fiber cleanup。
- S10：真实 compaction 事务、durable checkpoint 与 JSONL resume；仅摘要 seam 使用醒目标注的 deterministic fake。

三章均不需要 API Key。fixture / fake 只提供确定性外部输入，不替代被学习的 DSH 生命周期与持久化实现。

关键负向证据：

- S08 只丢弃 torn tail 的半条 JSON；已提交区损坏会在 Registry publication 前失败，原始字节不变。
- S09 exact-owner cleanup 不会取消 sibling owner 或 unowned job；若 producer 的 `cancel()` 违约抛错，Registry 只能 fail record，不能承诺实际工作已经停稳。
- S10 摘要失败会 durable 地闭合 failed bracket，不写 summary/checkpoint，也不替换 model-visible surface；`ManualCompactionError.cancelled` 另有覆盖。
