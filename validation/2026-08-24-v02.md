## 章节不变式

### S02 Service seam

- `GreeterDefinition` 是稳定 Service Definition，Friendly 与 Formal 是两个不同 Provider class；Consumer 不引用具体 Provider。
- declaration merging 只增强 TypeScript 类型，运行时注册来自 `Service` 构造器，运行时依赖来自 `inject`。
- 带 required `inject` 的 Consumer 可以先于 Provider 挂载，依赖缺失期间不运行主体。
- Provider 消失时 Service 登记撤销，Consumer 卸载自己的 effects。
- 同名替代 Provider 出现后，同一个 Consumer Fiber 使用新实现重新加载。
- 缺少 `inject` 时直接读取 `ctx.courseGreeter` 会得到稳定的 `without inject` 错误；`ctx.get()` 被保留为正确的 optional lookup。

### S03 Append-only session

- 已接受事件的 `seq` 从 0 连续递增，`session.seq === session.events.length`。
- append 对调用方输入做 detached snapshot 并深度冻结，调用方后续修改不能改写历史。
- `events` 是冻结、缓存的稳定快照；成功追加后生成新快照，旧快照不增长。
- BigInt 负例在 commit 前失败，不改变 length、seq 或 snapshot identity；随后合法事件复用未消耗的 seq。

### S04 Projection 与 replay

- 直接复用 S03 的两个 `todo/write` whole values；第二次完整列表胜出，没有新增教学 Session event。
- live incremental、同一 definition 的 manual full fold 与 seed replay 得到相同 todo 列表。
- seed replay 会增加 `session/end-seed`，因此只比较领域值，不错误断言日志长度或 `asOfSeq` 相同。
- 两个 `todo/write` 发布通知，`turn/start` / `turn/end` 返回原引用且不发布通知。
- 原地修改 state 并返回同一引用时，snapshot 值改变但 `onChanged` 静默；负向探针能稳定捕获这条错误。
